# ngx_mruby v2.7.11

## 更新前に確認する挙動の変更

- リクエストまたはレスポンスのヘッダのうち、別のヘッダの名前の接頭辞にあたる名前での削除が、長い方のヘッダを削除しなくなりました。以前は、`r.headers_in.delete("X-Foo")` が、`X-Foo-Bar` という名前のヘッダも削除していました。削除が、名前の先頭のバイト列だけを比較していたためです。これからは、ちょうど `X-Foo` という名前のヘッダだけを削除します。別のヘッダの接頭辞にあたる名前でヘッダを削除し、両方が削除されることに依存していた設定が、これに該当します。各ヘッダは、ちょうどの名前で削除してください。

## 新機能

ありません。

## 不具合の修正

- `Nginx::Var` のセッターと `Nginx::Var#set` が、set_handler を持つ変数（`$args` や `$limit_rate` など）に代入するようになりました。以前は、フィールドを埋めていない値の構造体を set_handler に渡していたため、代入した値が反映されず、その後にその変数を使うと worker プロセスが終了することがありました。値の構造体は、set_handler を呼ぶ前に、nginx と同じように埋めるようにしました
- 満杯のヘッダの list の part の途中から、リクエストまたはレスポンスのヘッダを削除したときに、その後にヘッダを追加しても、part の配列の末尾の先に書き込まなくなりました。また、list の最初の part が空になった直後に追加したヘッダを、保持するようにしました。削除は、残りの part の要素を手前へ詰めて要素を削除し、list の last の part のポインタを合わせるようにしました

## ビルドとテストの変更

- `test/t/cases/var_setter_init.rb`（`test/conf/conf.d/72-var-setter-init.conf`、ポート 18104、`test/html/var_setter_init.rb`）が、`Nginx::Var` のセッターと `Nginx::Var#set` で `$args` に代入し、読み戻します
- `test/t/cases/header_del.rb`（`test/conf/conf.d/73-header-del.conf`、ポート 18105、`test/html/header_del.rb`）が、リクエストのヘッダを削除します。ヘッダの接頭辞にあたる名前、2 つ目の part があるときに最初の part を空にする削除、満杯の part の途中からの削除とその後のヘッダの追加です

## アップグレード

- ディレクティブの追加、名前の変更、削除はありません。2.7.10 をビルドしたときと同じようにモジュールをビルドし直し、バイナリまたは動的モジュールをいつものように置き換えてください。`Nginx.module_version` は `2.7.11` を返します。

更新の前に、上の「更新前に確認する挙動の変更」を読んでください。
