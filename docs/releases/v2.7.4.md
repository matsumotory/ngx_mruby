## Build and test changes

- CI: a ready pull request that changes the code or the tests runs four cells of the `build` matrix of `test.yml`, not every cell (the 16 combinations of nginx version, link mode and `--with-openssl-src`, and the sanitizer cell). The four cells are nginx 1.31.8 with the static module and `--with-openssl-src`, nginx 1.30.6 with the dynamic module, the sanitizer cell (AddressSanitizer and UndefinedBehaviorSanitizer) and the cell under valgrind; the last two build nginx 1.31.8 with the static module. Every cell runs in the nightly run under valgrind, on the push of a tag, on a pull request with the new label `full-matrix` (the check pull request before a tag), and on "Run workflow" without the input `base` or with the input `valgrind`. A push to a `v*.x` branch runs no build, as a push to `master` or `next` does not. `test/ci/changes.sh`, the same script as on `next` again, takes the run as options (`--label`, `--draft`, `--push`, `--tag`, `--dispatch`, `--valgrind`) and gives `build` `standard`, `full` or `none` ("Which jobs a run starts" in [docs/test/README.md](../test/README.md)) (#704)
