# ngx_mruby v2.7.3

## Behavior changes: read before upgrading

None.

## New features

None.

## Fixes

None.

## Build and test changes

- nginx 1.31.8 and 1.30.6: `nginx_version`, which `build.sh` and `test.sh`
  read, names nginx 1.31.8 instead of 1.31.6, and CI builds nginx 1.31.8,
  1.30.6, 1.28.3 and 1.26.3 instead of 1.31.6, 1.30.5, 1.28.3 and 1.26.3,
  each as a static and as a dynamic module; the build with AddressSanitizer
  and UndefinedBehaviorSanitizer uses 1.31.8. nginx 1.31.7 and 1.30.6 fix the
  vulnerabilities in nginx that the
  [nginx security advisories](https://nginx.org/en/security_advisories.html)
  list as CVE-2026-15176, CVE-2026-93479, CVE-2026-95101, CVE-2026-97629 and
  CVE-2026-97205. A module that `build.sh` builds with its default nginx
  gets these fixes; a build that names its own nginx source with
  `NGINX_SRC_ENV` uses the nginx it names. ngx_mruby's code did not change
  for these versions. nginx's own changes are in its
  [CHANGES](https://nginx.org/en/CHANGES) and
  [CHANGES-1.30](https://nginx.org/en/CHANGES-1.30); among them, the HTTP/2
  module of 1.31.7 uses the RFC 9218 prioritization scheme and ignores RFC
  7540 priority signals, and 1.31.8 resolves the path of the
  `working_directory` directive against the nginx prefix instead of the
  current directory ([#638](https://github.com/matsumotory/ngx_mruby/pull/638)).

## Upgrading

Supported nginx versions: the nginx mainline and stable lines (see
[README.md](../../README.md)); CI builds nginx 1.31.8, 1.30.6, 1.28.3 and
1.26.3.

- No directive was added, renamed or removed. Rebuild the module with this
  release the way you built 2.7.2, and replace the binary or the dynamic
  module as usual.
