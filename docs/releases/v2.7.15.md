# ngx_mruby v2.7.15

## Behavior changes: read before upgrading

None.

## New features

None.

## Fixes

- The build links with GNU make 3.81, the make that macOS ships as `/usr/bin/make`. mruby's `libmruby.flags.mak` sets `MRUBY_PACKAGE_DIR` with `!=`, which GNU make 4.0 added, so make 3.81 left it empty and the link of nginx looked for `/lib/libmruby.a`. `Makefile.in` now sets the variable when it is empty; builds with GNU make 4.0 and later are unchanged (#872)

## Build and test changes

None.

## Upgrading

- No directive was added, renamed or removed. Rebuild the module with this release the way you built 2.7.14, and replace the binary or the dynamic module as usual. `Nginx.module_version` returns `2.7.15`.

Read "Behavior changes: read before upgrading" above before you upgrade.
