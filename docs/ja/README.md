# 日本語のドキュメント

ngx_mrubyのドキュメントは、英語のページが原文です。日本語のページは、その翻訳です。日本語訳があるページは、まだ一部です。

## 日本語で<wbr>読めるページ

- [v3.0.0のリリースノート](../releases/v3.0.0.ja.md)

## 日本語訳の<wbr>無いページ

サイトで日本語訳の無いページを`/ja/`の下のURLで開くと、英語の本文が出ます。本文の上には、日本語訳がまだ無いことを知らせる表示が出ます。英語のページの一覧は、[英語のドキュメントの一覧](../README.md#documents)にあります。
